# Cómo contribuir

¡Gracias por querer mejorar Zaynix!

1. Haz un fork y crea tu rama desde `develop`.
2. Corre las pruebas: `.venv\Scripts\python -m pytest -m "not red"`.
3. Abre un pull request hacia `develop` explicando qué cambia y por qué.

Al enviar un aporte confirmas que es tuyo, o que tienes permiso para compartirlo, y aceptas que se distribuya bajo la [GPL versión 3 o posterior](LICENSE). Conservas tu autoría.
